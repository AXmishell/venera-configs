## 创建新配置

1. 下载 `_template_.js`、`_venera_.js`，将它们放在同一目录中。
2. 将 `_template_.js` 重命名为 `your_config_name.js`。
3. 根据你的需求编辑 `your_config_name.js`：
   - `_template_.js` 文件包含注释，可帮助你完成编辑。
   - `_venera_.js` 用于在你的 IDE 中实现代码补全。
